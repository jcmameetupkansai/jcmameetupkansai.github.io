# JCMA関西支部 若手ミートアップ ランディングページ

`index.html` をブラウザで開けば表示できます。公開する場合は `site/` フォルダごと
Netlify Drop / GitHub Pages / 社内サーバー等にアップロードしてください。

## 第2回以降の更新手順

1. `data/meetups.js` を開く
2. 第1回の `status` を `'past'` に変更し、`report` に開催レポートを書く
3. 末尾のひな形（コメント内）をコピーして第2回を追加（`status: 'upcoming'`）
4. 第2回用の Google フォーム（第1回のフォームを「コピーを作成」）の回答用URLを `formUrl` に設定
5. 写真を追加する → 下記

トップのヒーロー・開催概要・申込ボタンは、`upcoming` の先頭1件から自動で切り替わります。
過去回は「アーカイブ」に新しい順で並びます。

## 写真の追加

1. `photos/01/`（第1回）、`photos/02/`（第2回）… に画像（jpg / png / webp）を入れる
   - 目安: 長辺 1600px 以下・1枚 500KB 程度（ページが軽くなります）
   - ファイル名の順（日付_連番など）で表示されます
2. `site/` フォルダで次を実行して一覧を更新

```bash
bash tools/build-photos.sh
```

3. サイトを再アップロード

※ 参加者が写っている写真は、申込フォームの「写真掲載への同意」を確認のうえ掲載してください。
